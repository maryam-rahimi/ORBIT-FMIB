# Code description

This repository contains the anonymized ESM-2 implementation and lightweight reproducibility artifacts for **ORBIT-FMIB**, a diagnostic framework for tracing order-resolved epistatic information through protein foundation-model representations.

## Core idea

For each complete WT-anchored GB1 mutational cube, ORBIT-FMIB applies a Walsh basis to both experimental fitness and frozen ESM-2 hidden representations. For each fixed positional subset $S$ and representation stage $\ell$, a subset-conditioned DV/MINE critic measures statistical dependence between the representation-level Walsh component and the corresponding experimentally measured epistatic coefficient. Peak-to-final retention is computed within each fixed subset before aggregation by interaction order.

The biological manuscript reports ESM-2 only. ESM-1v and ProtT5 development attempts are intentionally excluded from this release.

## Main scripts

| Script | Role |
|---|---|
| `01_validate_gb1_inputs.py` | Audits the GB1 tables and creates the label-free protein-model input index. |
| `02_validate_esm2_loading.py` | Verifies the frozen `esm2_t30_150M_UR50D` checkpoint, layer count, embedding width, tokenization, and target-site indexing. |
| `03_build_orbit_synth_fmib.py` | Builds controlled ORBIT-Synth interaction-order benchmarks with known ground truth. |
| `04_validate_mi_estimator.py` | Implements and validates the neural DV/MINE dependence estimator used by later analyses. |
| `05_run_orbit_synth_fmib.py` | Runs the end-to-end synthetic validation gate before biological interpretation. |
| `06_build_gb1_cubes.py` | Enumerates complete WT-anchored 4-site GB1 cubes and audits their 16-vertex structure. |
| `07_build_gb1_strict_split.py` | Constructs the amino-acid-identity-strict diagnostic split. |
| `08_build_esm2_extraction_index.py` | Creates the label-free sequence index used for frozen ESM-2 extraction. |
| `09_extract_esm2_representations.py` | Extracts the four assayed GB1 site representations at stages L0--L30. Large `.npy` arrays are regenerated by this script and are not committed. |
| `10_build_gb1_order_samples.py` | Constructs order-resolved Walsh samples that pair representation components with experimental epistatic targets. |
| `11_validate_gb1_null_controls.py` | Runs randomized-null diagnostics. |
| `11_validate_gb1_subset_conditioning.py` | Diagnoses the positional-subset shortcut in pooled critics and validates fixed-subset conditioning. |
| `11_validate_gb1_fixed_subset_sample_regime.py` | Validates the estimator under the exact biological dimensionality and train/validation/test sample regime. |
| `11_validate_relative_retention_calibration.py` | Validates relative peak-to-final retention behavior. |
| `11_validate_relative_retention_adversarial_suite.py` | Tests negative, flat, and positive order-selective retention patterns. |
| `11_validate_gb1_iid_vs_strict_split.py` | Performs the IID-versus-identity-strict diagnostic comparison. |
| `11_replicate_gb1_iid_split_seeds.py` | Evaluates pre-specified IID split-seed stability. |
| `11_run_gb1_subset_conditioned_mi_iid.py` | **Authoritative biological dependence run:** 31 layers × 15 fixed subsets × 3 critic seeds. |
| `12_aggregate_gb1_mi_fixed_subset_iid.py` | Organizes the 15 fixed-subset layerwise trajectories without reverting to pooled-by-order estimation. |
| `13_fixed_subset_retention_iid.py` | Applies the frozen null-floor eligibility rule and computes subset/order peak-to-final retention and the HO--LO contrast. |
| `14_bootstrap_retention_inference.py` | Contains the whole-identity deletion sensitivity analysis used for the reported `41=L` robustness check. Formal bootstrap inference is not reported in the manuscript. |
| `15_analyze_gb1_layerwise_dynamics.py` | Produces descriptive layerwise dynamics from frozen outputs without refitting critics. |
| `15_export_overleaf_results.py` | Exports the paper-facing retention tables, LaTeX macros, and order/subset-retention figures from the frozen Code 13/14 outputs. |
| `15_export_overleaf_results_replication.py` | Extends `15_export_overleaf_results.py` with an optional independent-replication overlay (order-level table columns, per-subset replication table, and Figure 4 lines) when `REPLICATION_INPUT_seed_results.csv` is present at the repository root; falls back to original-only output otherwise. |
| `16_make_gb1_layerwise_figures.py` | Generates the primary layerwise trajectory/transit/retention figure. |
| `16_make_gb1_layerwise_figures_replication.py` | Extends `16_make_gb1_layerwise_figures.py` with the same optional replication overlay, applied to Panels A and C of the main figure. |
| `19_build_subset_conditioning_validation_figure_v6.py` | Generates the estimator shortcut/correction validation figure from the released diagnostic artifacts. |

`11_run_gb1_target_mi.py` is retained because later audited validation scripts import or hash-check it as part of the provenance chain; it is not the final biological estimand.

## Interpretation boundary

The released DV/MINE values are **comparative neural dependence scores**, not calibrated absolute mutual information in nats. Critic-seed variation is an estimator-stability diagnostic, not biological sampling uncertainty. Order-level trajectories are descriptive averages formed only after within-subset estimation/normalization.

## Reproducing the manuscript outputs

The intended high-level order is:

```text
GB1 input audit
  -> ESM-2 loading/index audit
  -> ORBIT-Synth + estimator validation
  -> complete GB1 cube construction
  -> frozen ESM-2 extraction
  -> Walsh/order sample construction
  -> fixed-subset diagnostics/calibration
  -> authoritative fixed-subset biological run
  -> aggregation + retention
  -> layerwise analysis + figures
```

Lightweight authoritative CSV/JSON outputs are included under `04 Experiments/`. Large hidden-state arrays and model weights are intentionally excluded.
