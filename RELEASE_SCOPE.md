# Release scope

This repository is intentionally scoped to the ESM-2 analysis reported in the manuscript. ESM-1v and ProtT5 development/calibration attempts are not part of the biological result release.

The released neural-dependence scores are comparative DV/MINE measurements; they are not claimed to be calibrated absolute mutual information in nats.

For double-blind release, institution-specific execution comments were changed to generic HPC wording. These edits are documentation/comment-only; corresponding provenance hash references were updated consistently in the anonymous package.
