# Released experiment artifacts

This directory contains lightweight validation and production artifacts from the audited ESM-2 analysis.

- `EXP01_ORBIT_Synth/`: synthetic end-to-end validation manifest.
- `EXP03_MI/`: absolute/relative calibration, adversarial-retention, and exact-sample-regime validation artifacts.
- `EXP02_GB1_ESM2/`: GB1 estimator diagnostics and corrected-IID biological outputs.
- `EXP02_GB1_ESM2/IID_Production_20260910/Code15/`: descriptive layerwise analysis outputs.
- `EXP02_GB1_ESM2/IID_Production_20260910/Code16/`: primary layerwise figures and figure provenance.

Large frozen ESM-2 hidden-state arrays are excluded and can be regenerated with Code 09.
